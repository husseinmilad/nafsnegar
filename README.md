# نفس‌نگار

برنامه‌ی تحت وب (PWA) محاسبه‌ی نفس روزانه؛ بدون سرور، آفلاین و با تاریخ شمسی.

## انتشار روی GitHub Pages
1. در GitHub یک مخزن (Repository) جدید بسازید.
2. همه‌ی فایل‌های این پوشه را در ریشه‌ی مخزن آپلود کنید (Add file > Upload files).
3. به Settings > Pages بروید. در Source گزینه‌ی «Deploy from a branch» و شاخه‌ی main و پوشه‌ی root را انتخاب و Save کنید.
4. پس از یکی دو دقیقه، برنامه در آدرس https://USERNAME.github.io/REPO/ در دسترس است.

## نصب روی گوشی
آدرس را در Chrome باز کنید و از منوی سه‌نقطه «Install app» (افزودن به صفحه‌ی اصلی) را بزنید.

## نکته‌ها
- داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند؛ از تب «پشتیبان» خروجی بگیرید.
- اعلان‌های زمان‌بندی‌شده (اذان و ساعت ۲۳) فقط در نسخه‌ی اندروید (APK) کار می‌کنند.
- برای بروزرسانی، فایل‌ها را جایگزین کنید و عدد نسخه‌ی `CACHE` در `sw.js` را تغییر دهید (مثلاً v2).
- فونت وزیرمتن از Google Fonts بارگذاری و پس از اولین بازدید برای حالت آفلاین ذخیره می‌شود.
